## Highlights

### Unified Expedition Panels

Mercenary and drone expeditions now share the same structure:

```text
Active Expedition
Dispatch Settings
  Auto-dispatch
  Auto-claim
  Auto-resolve decisions
  Auto-choose
  Advanced
Mercenaries / Drone Status
Decisions
  Aggressive decisions
Archived Expeditions
```

- Expedition-specific settings moved into `Advanced`.
- Mercenary and drone labels/positions are aligned.
- The hardcoded mercenary destination behavior is unchanged.

### Per-Mode Auto-Claim

- **Mercenary**: `Auto-claim & pay rewards`
  - Pays the reward container and claims the mailbox.
  - If disabled, completed rewards stay pending until claimed manually.
- **Drone**: `Auto-claim rewards`
  - Independent of auto-dispatch; the drone can continue dispatching while rewards stay in the mailbox.

### Decision Policy

- Removed loot/risk score modifiers, score display, `Do not wait to auto choose`, and veteran-specific handling.
- Added a shared **Aggressive decisions** toggle for mercenary and drone decisions:
  - **Normal**: lower risk first; higher loot on ties.
  - **Aggressive**: higher loot first; lower risk on ties.
- Mercenary and drone decisions use the same shared policy module.

### Auto-Sell Removal

- Removed the “auto-sell cheapest items” feature and its setting.
- When the stash is full, mailbox claims now queue with a warning instead of selling items.

### Legacy Cleanup

- Removed the legacy `collect.all` reward path.
- Removed legacy drone claim wrappers/events.
- Removed the duplicate background decision timer; content-side resolution handles decisions.
- Removed the old modifier UI, related state, and helper-mode entries.

### Localization

This build includes the expanded Chinese localization:

- Language selector (English / 简体中文)
- Chinese section titles, toggle labels, statuses, and common dynamic labels
- `Market` rendered as `市场` while preserving market names/numbers
- Automatic translation of newly rendered popup content

## Installation

1. Download `cor3-helper-v1.8.3-salta.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup.

## Notes

- This is an experimental build. Expect behavior changes before the refactor is promoted to `main`.
- Warehouse sorting and mailbox auto-claim still use the existing Smart/Compact behavior from the stable release.
- `versions.json` is updated manually before releases (`npm run sync-versions` / `npm run release:prepare`).
