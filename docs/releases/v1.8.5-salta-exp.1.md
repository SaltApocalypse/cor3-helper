## Highlights

### Mercenary Automation

- Reduced the mercenary panel to two switches:
  - **Auto expedition**
  - **Add insurance**
- Automatic mercenary selection now uses:
  1. Elite USOL
  2. Normal USOL
  3. Normal CORE/HOME
  4. Total cost ascending inside each group
  5. Risk ascending as a tie-breaker
- Automatic reward payment/claiming is always enabled while auto expedition is on.
- Mercenary decisions are always resolved with the aggressive policy.
- Manual mercenary selection, auto-choose toggle, USOL-first toggle, ignore-elite toggle, cost limiter, and separate claim/decision switches were removed.
- Locations, zones and goals remain the existing hardcoded defaults.
- Detailed pause reasons are shown for missing mercenaries, missing config, insufficient credits, and transient failures.

### Drone Automation

- Reduced the drone panel to two switches:
  - **Auto expedition**
  - **Auto repair**
- Automatic mission selection uses:
  1. Lowest battery cost
  2. Lowest location risk
  3. Shortest duration
- Auto repair triggers when battery is below 30% or durability is at/below 60, repairs to 100, and waits without interrupting the repair.
- Repair failure pauses auto expedition and reports the reason.
- Drone decisions are always aggressive.
- Destination selection, full-charge waiting, auto-claim/decision toggles, repair thresholds, and pause-on-failure toggle were removed.

### UI & Localization

- Unified both Active Expedition headers to `margin: 8px 0 4px`.
- Replaced the drone expedition icon with the mercenary icon.
- Status tags now stay on one line; long titles truncate with an ellipsis.
- Expanded Chinese localization:
  - Hack → 破解
  - Objective automation labels
  - Auto Job Solver / Auto Valuable Seller UI
  - Loadout section labels
  - Bottom version/update bar
  - `Updated xx ago`
  - Common runtime/server errors
- Archived expeditions:
  - Mercenary `DEATH` → 死亡
  - Drone `DAMAGED` / `SEVERELY_DAMAGED` → 损坏 / 严重损坏
  - Loot format → `战利品（X 件）`
  - Completed time → `完成于 XX 时间`
  - Damage → 损伤
  - Drone archive layout aligned with mercenary archive cards.

### Removed

- Custom alarm feature (UI, audio scheduler, timer hooks and documentation).
- `chrome.alarms` remains in use for automatic job scheduling.

## Installation

1. Download `cor3-helper-v1.8.5-salta-exp.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and use the 🌐 button to switch language.
