## Highlights

### Language Selector

- Added a header language button (🌐) with **English / 简体中文**.
- The setting is stored as `uiLang` and can be switched at any time.
- Switching back to English restores the original text.

### Chinese UI Coverage

The first localization pass covers the main popup UI:

- Section titles:
  - Automation/QoL Toggles → 自动化/便利开关
  - Daily Ops → 每日行动
  - Markets → 市场
  - Expeditions → 远征
  - Inventory → 仓库
  - Loadout → 配装
  - Alarms → 闹钟
  - Pinned Timers → 固定计时器
- Toggle groups and labels:
  - Hack / Objective / QoL / Info Panel toggles
  - Auto Decrypt, ICE Wall, Simple Decrypt, Daily Hacking
  - Auto Job Solver / Auto Valuable Seller
  - Auto Update Markets, Secret Link/Server Finder
  - Desktop Glitch/Wave, Network Fog, Notifications
- Market names keep their names; only the word “Market” is translated:
  - Market-1 → 市场-1
  - Market-2 → 市场-2
  - Market-3 → 市场-3
  - Market-4 → 市场-4
  - HOME / D4RK / SOYUZ / USOL remain unchanged.
- Common dynamic labels:
  - Claimed / Streak / Difficulty / Bonus / Next Task
  - Cost / Risk / Loot / Battery / Durability / Status
  - Credits / Jobs / Items / Lots / Next reset
  - Rarity / Tag / Sell / Smart Sort / Compact Sort
  - Common statuses and expedition outcomes
- Newly rendered popup content is translated automatically while Chinese is active.

### Scope

- Game-provided item names, mercenary names, locations, and market names other than the word “Market” remain unchanged.
- The expedition system refactor is **not** part of this release; it is being developed on the `experimental` branch.

## Installation

1. Download `cor3-helper-v1.8.2-salta.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and use the 🌐 button to switch language.
