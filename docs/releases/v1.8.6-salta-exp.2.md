## Highlights

### Network Discovery

- Added a resumable hidden-connection discovery service.
- Saves scan progress in `localStorage`, so an interrupted scan resumes from the next IP instead of starting over.
- Adds a scan lock, progress reporting, a configurable time budget, and a last-result record.
- Skips discovery while Auto Job, Market automation, Valuable Seller, or another endpoint-changing task is active.
- Automatically retries discovery when a market has no known path.
- Refreshes the full network map after Auto Job or Valuable Seller finishes, so newly unlocked hidden routes can be captured.

### Network Diagnostics

- Added read-only snapshots with before/after diffs.
- Captures servers, connections, hidden connections, maintenance state, and endpoint changes.
- Added UTC and local timestamps to diagnostics and exported JSON.
- Added a full JSON download containing logs, snapshots, and the current map.
- Persists the complete `networkMapData` (`servers` + `connections`) for background routing.

### Dynamic Routing

- Background Auto Finish All Jobs now builds its route graph from the persisted full map, including hidden connections.
- Valuable Seller now prefers the live graph for endpoint routing and maintenance checks.
- Market path-through and Auto Job path-through now share `ServerMap` instead of duplicate DFS implementations.
- Background maintenance checks merge the fresher `serverMaintenanceMap` into the persisted map before routing.

### Loadout

- PSU selection now prefers maximum `psuPower`, then higher `psuProtection`, then the currently equipped part.
- Loadout application now re-fetches the loadout and verifies that the target software is actually equipped.
- If verification fails, the target software is equipped once more before the job continues.
- Auto Job and Valuable Seller debug logs use local time instead of UTC.

### Fixes

- Removed duplicate inline graph traversal code from market requests and the Auto Job message listener.
- Added automation-status bridge messages so discovery can detect when an endpoint-changing task is running.
- Fixed the background route check to respect fresh maintenance data even when the persisted map is older.

## Known Limitations

- Automatic discovery is wired to market no-path failures. It intentionally does not interrupt Auto Job while Auto Job owns the automation queue.
- Background does not initiate its own discovery yet.
- Static path maps remain as a bootstrap/fallback. The full dynamic-only migration is deferred to a later refactor.
- A real maintenance window is still required to validate background maintenance skipping end-to-end.

## Installation

1. Download `cor3-helper-v1.8.6-salta-exp.2.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and use the 🌐 button to switch language.
