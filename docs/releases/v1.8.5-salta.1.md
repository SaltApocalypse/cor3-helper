# COR3 Helper — Salta Fork Release

## v1.8.5-salta.1 — UI, Localization & Archive Update

> **This is a personal fork build**, not an official upstream release.
>
> - Fork: [SaltApocalypse/cor3-helper](https://github.com/SaltApocalypse/cor3-helper)
> - Original project / upstream: [Femtoce11/cor3-helper](https://github.com/Femtoce11/cor3-helper)

## Highlights

### Expedition UI

- Unified both Active Expedition headers to the same `margin: 8px 0 4px`.
- Replaced the drone Active Expedition icon with the mercenary expedition icon.
- Fixed expedition status tags so labels such as “准备中” stay on one line.
- Long expedition titles now truncate with an ellipsis instead of squeezing the status tag.

### Chinese Localization

- Changed “Hack” terminology to “破解”:
  - Hack Automation Toggles → 破解自动化开关
  - Auto Decrypt Hacking → 自动解密破解
  - Auto ICE Wall Hacking → 自动 ICE Wall 破解
  - Auto Simple Decrypt Hacking → 自动简单解密破解
  - Auto Daily Hacking → 自动每日破解
- Added translations for the Objective Automation section labels with emoji.
- Added translations for Auto Job Solver and Auto Valuable Seller UI labels, tabs, buttons, and empty states.
- Added translations for Loadout section labels:
  - Hardwares → 硬件
  - Softwares → 软件
  - System Overview → 系统总览
- Added `Updated xx ago` translations and refresh timestamps immediately when switching language.
- Localized the bottom version/update information bar.
- Added best-effort Chinese translations for common runtime/server errors, including insufficient credits, stash full, rate limits, repair failures, unreachable servers, job condition failures, and expired tokens.
- Dynamic debug log content remains in its original language.

### Archived Expeditions

- Mercenary archive:
  - `DEATH` → 死亡
  - Loot format → `战利品（X 件）`
  - Completed time → `完成于 XX 时间`
  - Added translations for faction, cost, risk, and collection status.
- Drone archive:
  - `DAMAGED` → 损坏
  - `SEVERELY_DAMAGED` → 严重损坏
  - `DESTROYED` → 已摧毁
  - Renamed “伤害” to “损伤”
  - Unified loot format to `战利品（X 件）`
  - Added completion time display.
- Drone archived cards now follow the mercenary layout:
  - Mission header and outcome
  - Location / risk / damage
  - Expandable loot list with item icons, names, tiers, and collection status
  - Completion timestamp

### Scope

- This release contains UI, localization, error-message, and archived-expedition updates only.
- The experimental two-switch automation simplification and alarm removal are **not** included.
- The expedition automation refactor remains on the `experimental` branch.

## Installation

1. Download `cor3-helper-v1.8.5-salta.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and use the 🌐 button to switch language.
