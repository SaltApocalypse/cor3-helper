## Highlights

### Daily Ops

- Consolidated Daily Ops into one standalone card below the Automation/QoL toggles.
- Removed the old separate Daily Ops information panel and the Info Panel visibility toggle.
- Added diagnostics with copy/clear controls and fixed the horizontal scrollbar on long log lines.
- Added English/Chinese puzzle-title detection for **System Log Integrity / 系统日志完整性** and **Signal Hack / 信号解码**, plus a DOM fallback.
- **Persistent switch:** once enabled, Auto Daily Hacking stays on instead of disabling itself after a run.
  - Checks on page load and when the page regains focus.
  - Waits for the API's next reset time after a successful or already-claimed run.
  - Retries later after a failed run.
  - Shows the next automatic check time in the popup.
  - Uses a run lock to avoid duplicate runs from multiple tabs.

### UI

- Top-level sections from Automation/QoL onward are now independent cards with consistent spacing.
- Fixed the undefined `--bg-section` variable so panel backgrounds render correctly.
- Kept popout and side-panel layouts free of double card borders.
- Pinned timers, Markets, Expeditions, Inventory, Loadout, and DevTC use the same card treatment.
- Version/footer content remains outside the feature cards.

### Auto Valuable Seller

- The select-all control is now sticky at the top of the Servers and Downloads lists, so all search results can be selected without scrolling to the bottom.
- Label localized as **Select All Results / 全选结果**.

### Version Tracking

- `versions.json` updated to web `v1.25.80` and patch `3.104.9`.
- Version warnings now use clearer "reference version" wording.
- Fixed the System version warning writing to the wrong DOM element.
- Version comparison uses the newer of the bundled reference and remote fork reference.
- `sync-versions` merges upstream values without downgrading newer fork values and uses a 15-second network timeout.

## Experimental Branch Notes

This release keeps the experimental-only automation changes from the previous experimental release:

- Simplified mercenary automation with **Auto expedition** and **Add insurance**.
- Simplified drone automation with **Auto expedition** and **Auto repair**.
- Aggressive decision policy.
- Custom alarm feature removed.
- `chrome.alarms` remains in use for automatic job scheduling.

## Installation

1. Download `cor3-helper-v1.8.6-salta-exp.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and use the 🌐 button to switch language.
