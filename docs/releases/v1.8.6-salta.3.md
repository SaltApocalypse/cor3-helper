> - Previous stable release: [v1.8.6-salta.2](https://github.com/SaltApocalypse/cor3-helper/releases/tag/v1.8.6-salta.2)

## What changed

### Loadout verification

- Loadout application now verifies that the target software is actually present after equipping.
- The helper re-fetches the loadout instead of trusting the previous cached state.
- If the target software is still missing, it re-equips the software once and verifies again.
- This prevents the observed sequence where a plan was applied but the next check still reported `0 equipped software` and insufficient power.
- Both Auto Job Solver and Auto Valuable Seller use the same verification behavior.

### PSU selection

- When multiple hardware combinations achieve the same target power, the resolver now prefers:
  1. higher `psuPower`;
  2. higher `psuProtection`;
  3. the currently equipped hardware.
- This avoids choosing a lower-power PSU that satisfies only the current calculation but leaves no headroom.

### Debug logs

- Auto Job Solver and Auto Valuable Seller debug log timestamps now use local time instead of slicing the UTC ISO timestamp.

### Scope

- This hotfix contains Loadout and log-timestamp fixes only.
- Network Discovery, Network Diagnostics, and dynamic routing remain on the `experimental` branch.
- No new permissions are required.

## Installation

1. Download `cor3-helper-v1.8.6-salta.3.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
