## Highlights

### Mercenary Insurance

- Added an **Add insurance** toggle to the Mercenaries settings.
- The setting is stored as `autoSendMerc.hasInsurance` and defaults to off.
- Insurance is only available for mercenary expeditions.
- Both the `configure` quote and the actual `launch` request now send the same
  `hasInsurance` value.
- Mercenary cards, the cost limiter, and auto-choose use insured costs when the
  toggle is enabled.
- Toggling insurance refreshes mercenary configure data so displayed costs stay
  accurate.

### Localization

- Added Chinese labels for the insurance toggle and the active-expedition
  insurance fields:
  - Add insurance → 添加保险
  - Insurance: Yes/No → 保险：是/否
  - Only mercenary expeditions support insurance. → 仅雇佣兵远征支持保险。

### Scope

- This release contains only the mercenary insurance feature and its
  documentation/localization updates.
- The expedition-system refactor remains on the `experimental` branch and is
  **not** part of this stable-line release.

## Installation

1. Download `cor3-helper-v1.8.4-salta.1.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
6. Open the extension popup and enable **Add insurance** under Mercenaries if desired.
