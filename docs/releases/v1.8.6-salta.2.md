## What changed

### Loadout selection

- Hardware is now scored by the ability needed for the current task:
  - `DECRYPT` for decryption jobs
  - `HACK` for server access
  - `SEARCH` for valuable-file searching
- Software candidates are evaluated by their **achievable power with the player's owned hardware**, not only by their theoretical maximum power.
- The resolver now searches software × hardware combinations and skips combinations that cannot boot.
- Fixed decryption loadout selection skipping hardware optimization when the preferred software was already equipped.
- Fixed retry logic always taking the first software candidate.
- Current software/hardware is preferred when the achievable power is equal, reducing unnecessary equipment churn.
- Diagnostics now include the selected software, target power and hardware names.

### Scope

- This hotfix contains the Loadout changes only.
- Network-map diagnostics and architecture work remain on the `experimental` branch.
- No new permissions are required.

## Installation

1. Download `cor3-helper-v1.8.6-salta.2.zip` from this release.
2. Extract the archive to a folder.
3. Open `chrome://extensions/` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder (the one containing `manifest.json`).
5. Open [cor3.gg](https://cor3.gg) and log in.
